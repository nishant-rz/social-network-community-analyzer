Algorithm · Louvain modularity

Finds groups with many friendships inside and fewer between them.

  1. Start with each person in a separate group.
  2. Move a person to a neighbouring group when modularity improves.
  3. Merge groups and repeat until no improvement is found.

Q = Σᵢ [ lᵢ / m − ( dᵢ / 2m )² ]

lᵢ: links within group i · dᵢ: total degree in group i · m: total links

Louvain pseudocode

function LOUVAIN(graph):
    give each person their own community

    repeat:
        improvement = false

        for each person in graph:
            old_group = person's community
            best_group = old_group
            best_gain = 0

            for each neighbouring community:
                temporarily move person to that community
                gain = change in modularity
                undo the temporary move

                if gain > best_gain:
                    best_gain = gain
                    best_group = neighbouring community

            move person to best_group
            if best_group is not old_group:
                improvement = true

        combine each community into one super-node
        keep the edge weights between super-nodes

    until no modularity improvement is possible

    return the communities of the original people

The implementation calls NetworkX's Louvain routine; the steps above show its main idea.

Discrete math concepts

Sets & logic

People as a set; mutual friends as intersection.

Relations

Friendship is a symmetric relation; communities partition the set.

Graph theory

People are vertices, friendships are edges; paths measure connection.

Counting
