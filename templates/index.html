Discrete mathematics concepts used

These course ideas define the network model and explain the dashboard's results.

Sets and predicates

People form the vertex set V. A friendship predicate is true when an edge joins two people; CSV validation also checks conditions such as positive weight.

Relations and functions

Friendship is a symmetric binary relation R ⊆ V × V. The community label is a function c: V → {0, …, k−1}.

Partitions and equivalence classes

Louvain assigns every person to one community, producing a partition of V. Sharing a community label defines an equivalence relation for that partition.

Counting combinations

For an undirected network of n people, there are C(n, 2) possible distinct pairs. The edge list records which pairs have a relationship.

Graph theory

The project models a weighted, undirected graph G = (V, E). Degree counts direct neighbours; edge weights represent friendship strength.

Paths and shortest paths

A path is a sequence of connected vertices. Dijkstra finds a minimum-cost route, using cost 1 / weight so stronger ties cost less.

Graph partitions and modularity

Modularity compares within-community edges with the number expected from node degrees. A larger Q indicates stronger community structure for this graph.

Algorithms used

Louvain community detection

Moves nodes between neighbouring groups to increase modularity, then aggregates groups and repeats.

Q = Σᵢ [ lᵢ / m − ( dᵢ / 2m )² ]

lᵢ: edges inside group i · dᵢ: sum of degrees in group i · m: total edges

function LOUVAIN(graph):
    put each node in its own community
    repeat:
        move each node to a neighbouring community
            when the move increases modularity
        merge each community into a super-node
    until modularity no longer improves
    return the communities

The Python backend calls NetworkX's Louvain implementation with a fixed seed for repeatable results.

Dijkstra shortest path

Finds the lowest-cost route between the two selected people. Each edge cost is the reciprocal of its friendship weight.

function DIJKSTRA(graph, start, target):
    distance[start] = 0
    distance[all other nodes] = infinity
    repeatedly choose the unvisited node with least distance
    for each neighbour of that node:
        cost = 1 / edge weight
        if current distance + cost is smaller:
            update the neighbour's distance and predecessor
    follow predecessors back from target to build the path
    return the path, or report that none exists

The browser JavaScript runs this routine for the selected pair and highlights the resulting route.
